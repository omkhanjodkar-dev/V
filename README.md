# V (C++ Terminal Text Editor) [Experimental]

A single file cpp terminal text editor experiment using a customised doubly linked list with size and feature customization for terminal text boxes.

## How to run it?
Run this command on a Windows environment:

`make build_and_run`

It's mainly built and tested on a Windows environment, but to run it on Linux you would compile main.cpp with gcc and run the output file.

## How to use custom text boxes?
Although I haven't made header files here, you could extract the needed classes from the main.cpp file and create custom features editable terminal text boxes at some position with some size.

## Note
There are still multiple bugs and significant inefficiencies within the code and I would not recommend to use this for real world application. Consider it for experimenting and testing only.
